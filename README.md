This repository contains the dataset and script for the paper:
Implementing a Deterministic Validator Framework to Quantify Reliability Gaps in AI-Generated UAV Pathfinding Logic

// Files Included
- `ai_path_validator_script.py`: Validator script that evaluates whether UAV coordinates generated by LLMs satisfy physical constraints.
- `rp results data.xlsx`: Contains the prompts provided to and responses received from the tested LLMs.
